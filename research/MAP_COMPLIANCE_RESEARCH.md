# Map Compliance & Spatial Visualization Research — China Data Atlas (R2)

- **研究日期（UTC）**：2026-11-24
- **研究目标**：系统核实自然资源部标准地图服务、天地图官方服务、《地图管理条例》与《公开地图内容表示规范（2023）》对公开网站中国省级动态专题地图的法律、许可、技术与部署约束，评估至少两种候选方案，并给出 Round 2 可落地工程架构。

---

## 1. 适用法律法规与核心合规红线

1. **《地图管理条例》（国务院令第 664 号）**：
   - 第十五条：国家实行**地图审核制度**；向社会公开的地图，应当报送有审核权的测绘地理信息行政主管部门审核（直接使用自然资源部标准地图且**未对底图内容进行任何修改**的除外）。
   - 第三十四条：互联网地图服务单位应当取得相应测绘资质，并建立地图内容安全审核机制。
2. **《公开地图内容表示规范》（自然资规〔2023〕2 号，2023-02-06 印发）**：
   - 中国全图必须完整准确表示领土范围（东至黑龙江与乌苏里江交汇处、西至喷赤河、北至黑龙江最北江段、南至曾母暗沙以南），**必须表示南海诸岛、钓鱼岛及其附属岛屿**，任何专题要素与图例严禁压盖重要岛屿；
   - 台湾省按省级行政单位表示，香港、澳门特别行政区准确表示边界与名称。
3. **动态专题着色（Dynamic Choropleth）的法律边界**：
   - 将来源不明的开源中国 GeoJSON（如未审图 GitHub 仓库或自行简化的边界）叠加动态数据着色公开发布，极易出现漏绘南海诸岛、错绘国界/省界等“问题地图”风险；
   - 即便下载标准地图底图，若进行**矢量边界编辑、重新着色、叠加自定义业务专题图层并向社会公开发布**，亦可能构成地图内容变更而触发重新送审要求。

## 3. 两种候选实施方案深度评估

| 评估维度 | 方案 A：天地图官方 JS API / WMTS 瓦片底图 + 合规业务叠加 | 方案 B：自然资源部标准地图审图底图 + 自研静态/交互专题层 |
|---|---|---|
| **地图来源** | 国家地理信息公共服务平台（天地图 `tianditu.gov.cn`） | 自然资源部标准地图服务（`bzdt.ch.mnr.gov.cn`，如 GS(2024)XXXX） |
| **许可与费用** | 基础底图瓦片与标准 API **免费**（个人/企业均可注册获取 `tk` Key）；个人配额约 1 万次/日，企业认证后更高；须保留天地图版权与审图号标识 | 标准地图免费下载；**仅原样未修改使用可免审**；商用/媒体/出版须显著标注审图号 |
| **动态专题着色合规性** | 调用官方标准底图叠加点位/标绘通常依托底图自身审图号；但自定义省级多边形填充（Choropleth）仍需官方合法省界数据且不得压盖南海诸岛/钓鱼岛 | 对标准地图进行矢量二次编辑、动态填充配色并公开发布，**依法需向省级以上自然资源主管部门重新报审**并取得新审图号 |
| **中国大陆 vs 海外部署** | 大陆访问稳定；**海外 IP 实测触发 HTTP 418 WAF 拦截或超时**；且需绑定实名开发者 `tk` 与域名白名单 | 静态资源无跨国 WAF，但审图送审与主体备案通常需要中国境内合法法人/备案主体 |
| **是否需要用户授权** | **是**（需用户以个人/企业主体实名注册天地图账号、申请 `tk` Token 并配置域名白名单） | **是**（需项目运营方履行自然资源主管部门地图内容送审流程） |
| **未解决法律/技术阻塞** | ① 需用户授权实名 `tk` Key；② 海外 Vercel 访问天地图瓦片受 WAF 限制；③ 动态多边形面填充仍需核验官方矢量边界许可 | ① 当前海外网络无法访问 `bzdt.ch.mnr.gov.cn`；② 动态交互式专题着色需正式地图审核批号（审图号） |

## 4. Round 2 推荐与实际落地工程方案

基于上述法律核实与实时可达性实测，Round 2 做出**负责任且面向未来可扩展的工程决策**：

1. **绝不违规冒险**：不引入任何未经审图核验的第三方中国 GeoJSON，不伪造审图号，不声称已完成地理边界交互地图模块（`EVALUATION.json` 中诚实标注 `map_status: "deferred_with_pluggable_provider_interface"`）。
2. **交付研究级非地图合规空间替代视图**：升级七大区域省级矩阵热力图（支持单年/多指标/年份切换/点击下钻省份档案页/缺失斜纹置灰/区域加权对比/港澳台统计覆盖单列说明），彻底消除任何边界合规风险。
3. **交付可插拔地图组件接口（`SpatialViewProvider`）**：在前端实现标准化的 `app/src/components/SpatialViewAdapter.tsx` 契约接口，明确定义 `mode: "regional_matrix" | "reviewed_choropleth"` 与环境变量 `NEXT_PUBLIC_TIANDITU_TK` / `NEXT_PUBLIC_MAP_APPROVAL_NO`。一旦运营方完成天地图企业/个人 `tk` 授权（配中国大陆可访问节点）或取得自然资源部审图号及合规矢量底图，即可零重构接入交互式省级专题地图。
